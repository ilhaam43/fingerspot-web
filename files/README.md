Private Word form templates are excluded from this public repository.
Supply your own templates in this folder to enable the corresponding Word/PDF
form exports. The local Docker setup mounts this directory read-only.

Expected filenames:

- template-cuti.docx
- template-lembur.docx
- template-status-kehadiran-dinas.docx
- template-status-kehadiran-lainnya.docx
- template-status-kehadiran-sakit.docx
- template-status-kehadiran-tl.docx
- template-status-kehadiran-tp.docx
- template-tukar-shift.docx
